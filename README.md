# 小学四则运算题目自动生成程序

软件工程结对编程作业：命令行四则运算题目生成器与批改器。

## 1. 环境要求

* Python 3.10 或更高版本（开发与测试使用 Python 3.12.7）
* 只依赖 Python 标准库；运行单元测试需要 pytest

## 2. 运行方式

### 2.1 生成题目

```text
python main.py -n 10 -r 10
```

* `-n`：生成题目的个数，缺省为 10；
* `-r`：题目中数值（自然数、真分数及其分母）的范围，**必须给定**，数值满足 `0 <= 数值 < r`。

生成结果写入当前目录下的 `Exercises.txt` 与 `Answers.txt`：

```text
1. 7 ÷ (7 × 9) + 7/9 = 
2. 3/4 - 1/9 ÷ (2 - 3/7) = 
```

```text
1. 8/9
2. 269/396
```

真分数写作 `3/5`，带分数写作 `3’2/5`（即 3 又 2/5）。

### 2.2 批改答案

```text
python main.py -e Exercises.txt -a Answers.txt
```

程序会把 `Exercises.txt` 的每道题重新解析、重新计算，再与 `Answers.txt` 比较，
统计结果写入当前目录下的 `Grade.txt`：

```text
Correct: 5 (1, 3, 5, 7, 9)
Wrong: 5 (2, 4, 6, 8, 10)
```

### 2.3 测试与效能分析

```text
python -m pytest -q          # 68 个单元测试
python profile_checker.py    # cProfile 分析，生成 profile.prof 与 benchmark.csv
```

## 3. 题目约束

| 约束 | 实现方式 |
| --- | --- |
| 计算过程不出现负数 | 合并减法节点时保证 `e1 >= e2`（必要时交换左右操作数） |
| 除法的商是真分数 | 合并除法节点时保证 `0 < 被除数 < 除数`，商必然满足 `0 < 商 < 1` |
| 每道题运算符不超过 3 个 | 生成时随机取 1 ~ 3 个运算符 |
| 题目不能重复 | 用规范键去重：`+`、`×` 的子节点排序，`-`、`÷` 保持左右顺序 |
| 支持一万道题目 | 实测 `-n 10000 -r 10` 纯生成耗时约 0.34 秒 |

补充说明：

* 当 `-r` 小于 3 时不存在满足「商为真分数」的两个操作数，程序会自动不使用除号，
  保证 `-r 1`、`-r 2` 也能正常出题；
* 当 `-r` 太小、题目空间被抽干时，程序会给出明确提示并退出，而不是死循环。

## 4. 目录结构

```text
3124004429/
├── main.py                  # 命令行入口
├── arithmetic/              # 核心包
│   ├── errors.py            # 自定义异常
│   ├── fraction_text.py     # 真分数文本格式化与解析
│   ├── expression.py        # 表达式树：求值、渲染、规范键
│   ├── generator.py         # 题目生成器
│   ├── parser.py            # 题目文本解析器
│   ├── grader.py            # 批改与统计
│   ├── files.py             # 文件读写
│   └── cli.py               # 参数解析与流程编排
├── tests/                   # 68 个 pytest 用例
├── baseline_naive.py        # 优化前的朴素实现（性能对比用）
├── profile_checker.py       # 效能分析脚本
├── docs/figures/            # 博文用图
└── samples/                 # 示例输出
```

## 5. 退出码

* `0`：执行成功；
* `2`：参数错误、文件不存在或文件格式不符（会打印 `error:` 提示与帮助信息）。
